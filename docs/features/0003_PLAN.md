# 0003 — Scribble Stickers Replace Letter Recognition

## Context

HurufPad currently tries to turn a child's scribble into a recognized letter. On-device recognition is not accurate enough to be worth it, so we drop it.

Instead, a scribble becomes a **scribble sticker**: the raw ink is kept as-is and promoted to a movable board object that behaves like a letter sticker — draggable, lasso-selectable, auto-aligned into a row, erasable, and editable in the inspector. It cannot be spoken, because there is no glyph to read.

Two supporting features come with the pivot:

- Selecting the Pencil tool opens a submenu under it for **stroke color** and **stroke type** (pencil, crayon, chalk, marker) plus stroke weight.
- Once a scribble is a sticker, the inspector edits its **color, stroke type, and stroke weight**.
- Editing a selected scribble's inspector properties also updates the defaults for the next scribble.
- Newly added letter stickers use a random color from the approved palette.

Everything else stays working: Add Sticker letter grid, caps lock, hand/eraser/lasso tools, row alignment, Speak, pan/pinch/zoom.

## Confirmed requirements

- Remove only scribble→letter recognition. Add Sticker and all other functions stay functional.
- A scribble becomes a sticker on a settle timer: all strokes drawn within ~1s of each other group into **one** scribble sticker.
- Stroke types differ by width, opacity, line cap, and tension only. No textured or pattern brushes.
- The Speak button is **disabled** whenever the selection contains a scribble.
- Scribble inspector exposes color, stroke type, and stroke weight. It does not expose Size.
- Lasso alignment treats scribbles like letters, using their bounding-box width.
- After selecting multiple objects with Lasso, switching to Hand keeps the selection and dragging any selected object moves the whole selection together.
- After selecting multiple objects with Lasso, switching to Eraser keeps the selection and bounding boxes visible; tapping any selected object deletes the whole selected set.
- The pencil submenu sets defaults for **new strokes only**; it does not mutate the current selection.
- The scribble inspector mutates the selected scribble and also sets the same property for the next scribble object.
- Add Sticker creates each new letter with a random color from the approved palette instead of always using the default color.
- Eraser tap deletes the whole scribble sticker.

## Data model

`Board.letters: Letter[]` becomes `Board.items: BoardItem[]`, a discriminated union on `kind`.

- `LetterItem` — today's `Letter` plus `kind: 'letter'`.
- `ScribbleItem` — `kind: 'scribble'`, `id`, `x`, `y`, `width`, `height` (natural ink bounds), `strokes` (normalized so the bounds origin is `0,0`), `fill`, `brush`, `weight`.

Normalizing stroke points to the bounds origin means moving a scribble only changes `x`/`y`, and rendering is a Konva `Group` positioned at `x,y`.

A union is used rather than a second parallel array so that move, remove, select, lasso hit-test, align, and z-order stay single-implementation.

## Algorithms

### Scribble commit (settle timer)
1. Pencil pointer-down appends a new stroke to the pending stroke list and cancels any running timer.
2. Pointer-move appends points to the last pending stroke.
3. Pointer-up starts a timer for `inkSettleMs`.
4. Drawing again before it fires cancels it, so consecutive strokes accumulate into one pending group.
5. On fire (or on "Make sticker"), compute the padded bounds of all pending strokes, subtract the bounds origin from every point, build a `ScribbleItem` at those bounds with the current `inkStyle`, add it to `items`, select it, and clear the pending ink.

### Stroke rendering
Board-space stroke width is `strokeWeights[weight] * brushes[brush].widthScale`. Opacity, `lineCap`, `lineJoin`, and `tension` come from the same preset. Colour is the item's `fill`.

Note the current pending-ink width is `8 / viewport.scale`, which keeps a constant on-screen thickness but a zoom-dependent board-space thickness. Drop the division so the preview matches the committed sticker and scribbles zoom like letters.

### Scribble hit-testing and drag
The Konva `Group` sits at `x,y`; its hit region is the union of its lines widened by `hitStrokeWidth`. Drag end writes the group position back through `moveItem`. Eraser pointer-down on the group calls `removeItem`. Lasso continues to test the item's bounding-box centre against the polygon, now via `getItemDimensions`.

### Alignment with mixed selection
Unchanged apart from the dimension source: sort selected items left-to-right, take the median `y` as the shared baseline, keep the group's left edge at the minimum `x`, then lay items out with `letterGap` between them using each item's `getItemDimensions` width.

### Multi-selection drag
After Lasso selects multiple objects, switching to Hand does not clear selection. Pointer-down on any selected object keeps the whole selected set. On drag-start, snapshot each selected item's original `x/y`; on drag-move, compute `delta = draggedCurrentPosition - draggedOriginalPosition`, then write every selected item to `originalPosition + delta`. Pointer-down on an unselected object still selects only that object.

### Multi-selection erase
After Lasso selects multiple objects, switching to Eraser does not clear selection. Selection outlines stay visible. Tapping any selected object removes the full selected set in one reducer call. Tapping an unselected object removes only that object.
