# BoardCanvas (main board)

HurufPad’s board is a Konva canvas of letter **stickers** (clip-art glyphs in a real font). Kids scribble with Pencil; after **180ms** of no new strokes (or an immediate transform button) a **stub** recognizer returns A–Z / a–z plus confidence. High confidence becomes a sticker; low confidence opens a **popover picker** attached to the scribble. Hand pans or moves/edits stickers. **Add Sticker** opens an on-screen A–Z / a–z grid (caps lock); taps insert stickers in a **left-to-right row** (next glyph to the right of the last placed sticker, same gap as lasso align). Lasso selects arranged letters; if the selection is **not already aligned**, stickers snap into a **left-to-right row** using their current relative order, then Speak can read them **left-to-right** via `speechSynthesis` in the current language. **Indonesia is default**; the toggle shows a **flag icon and label**. On-device ML is **not** in this increment: recognition is a stub with a stable `recognize(strokes)` interface for a later TensorFlow.js/ONNX model. Hardware keyboard insert and last-session persistence stay out of this plan.

## Types and pure board functions

Extend [`src/board/types.ts`](../../src/board/types.ts) and add [`src/board/board.ts`](../../src/board/board.ts) (pure functions, new state, no classes):

- **Language:** `'id' | 'en'`; `emptyBoard()` default **`'id'`**.
- **Tool:** `'hand' | 'pencil' | 'lasso' | 'addSticker'`; default **`'pencil'`**.
- **Letter sticker:** `id`, `glyph`, `x`, `y`, discrete **size** `S | M | L | XL` (pixel heights live in tokens, e.g. 56 / 80 / 112 / 144), `fill` from `letterFills` only, `fontFamily` from `boardFontFamilies`.
- **Caps lock (Add Sticker only):** boolean; `false` → a–z grid, `true` → A–Z grid. Does not change existing stickers.
- **Placement anchor:** `lastPlacedStickerId` (id of the sticker last created by Add Sticker). Used so sequential taps stay in one row.
- **Stroke / pending ink:** polyline points in **board space**; a pending group is the current multi-stroke letter (timer resets on each new stroke).
- **Viewport:** `scale`, `x`, `y` on the Stage (not stored as letter data). Initial zoom is `scale = 1`, `x = 0`, `y = 0`.
- **Selection:** `selectedIds: string[]` (hand = one sticker; lasso = many).
- Reducers: add/move sticker, **place sticker from grid** (next to last placed), set size/fill/font, replace pending ink with sticker, set tool/language/caps, set selection, **align selected stickers left-to-right**.

Named constant **`RECOGNITION_PAUSE_MS = 180`** (easy to change later). Named **confidence threshold** for auto-commit vs picker.

## Algorithms

**Pan / zoom (Konva Stage)**

1. Store `scale`, `stageX`, `stageY`.
2. Wheel (and pinch on touch): scale around the pointer; clamp min/max scale.
3. **Hand:** pointer on empty board pans the Stage; pointer on a sticker selects it and drags that sticker (board coords). Pencil and Lasso do not pan via drag.
4. **Reset zoom** button: `scale = 1`, `stageX = 0`, `stageY = 0`.

**Scribble → sticker**

1. Pencil down/move/up appends points to the current stroke; stroke end starts a **180ms** timer.
2. New stroke before the timer fires **cancels** the timer and continues the same pending letter (multi-stroke, e.g. E, T, K).
3. Timer fire **or** transform button: pass all pending strokes into `recognize(strokes)`.
4. Stub `recognize` in [`src/board/recognize.ts`](../../src/board/recognize.ts): same return shape as a future model (`glyph`, `confidence`, `alternatives: glyph[]` for A–Z / a–z). Stub should sometimes be **below** threshold so the picker can be built (e.g. always show a short candidate list, or flip confidence with a flag). Does **not** send ink off-device.
5. Confidence ≥ threshold: drop a sticker at the ink bounding box, clear pending ink.
6. Confidence low: keep ink visible; show picker popover **attached to the scribble bounds** (stage → page coordinates). Choosing a tile commits that glyph and clears ink. Dismiss without choice leaves ink until transform again or a new scribble policy (prefer: picker stays until a tile is chosen or the user starts a new scribble / switches tool).
7. Transform button commits **all untransformed pending ink** through the same path (one pending group in v1).

**Lasso + align + speak**

1. Lasso draws a freehand path in board space; on pointer up, close the path.
2. Stickers whose **center** is inside the polygon become `selectedIds`.
3. If **two or more** stickers are selected and they are **not aligned**, run **align left-to-right** (pure function in `board.ts`). If they already form a row, leave positions unchanged.
4. **Aligned** means they share a baseline (max `y` difference below a small named tolerance) and sit in left-to-right order with even-ish gaps (optional: skip realign when already a row so a tidy syllable does not jump).
5. **Align algorithm** (preserve relative reading order, do not invent a new order):
   - Sort selected stickers by current **`x` then `y`** (relative position on the board).
   - Keep the group’s **left edge** (`min x`) and a shared **baseline `y`** (median of selected `y`, so the cluster does not jump vertically).
   - Place them in that sort order on one horizontal line: each sticker’s `x` is previous right edge plus a named **letter gap** (from tokens / `--space-*`); each sticker keeps its own S/M/L/XL width/height; all `y` set to the shared baseline (top-left origin: use the same top `y` so different sizes sit on one line — prefer **shared top** for clip-art stickers, not typographic baseline).
   - Animate with existing `--duration` / `--ease` if cheap on Konva; otherwise snap.
6. Speak concatenates selected glyphs **left-to-right** (same sort as align: `x` then `y` after align). Label the control (not color-only), accent style per DESIGN.
7. **TTS language (must follow the toolbar selection)** in [`src/board/speak.ts`](../../src/board/speak.ts):
   - Board **Indonesia** → preferred BCP-47 `id-ID`; board **English** → preferred `en-US`.
   - Always set `SpeechSynthesisUtterance.lang` to that preferred tag so the engine knows the language even when no named voice is bound.
   - Pick a voice from `speechSynthesis.getVoices()` in this order:
     1. Exact match on `voice.lang` (case-insensitive), e.g. `id-ID` or `en-US`.
     2. Else **any voice whose language matches the selected language family**: `voice.lang` prefix `id` (e.g. `id`, `id-ID`) or prefix `en` (e.g. `en-GB`, `en-AU`, `en`).
     3. Else leave `utterance.voice` unset and still speak with `utterance.lang` set (browser default). Do **not** silently switch Indonesian speech to English or the reverse when a matching-family voice exists.
   - Voices may load asynchronously (`voiceschanged`); resolve voices at speak time, not only at boot.
   - Do not assume an Indonesian voice exists on every device.

**Add Sticker (on-screen letter grid)**

1. Selecting the **Add Sticker** tool shows a letter grid (like an on-screen keyboard): 26 tiles A–Z or a–z, plus a labeled **Caps lock** toggle (`aria-pressed`). Tiles reuse the letter-picker pattern (glyph ≥ 56×56, `--tap-min`, `.btn`). Grid is a board-adjacent panel (bottom or toolbar overflow), not a modal that covers the whole canvas.
2. Caps lock **on** → uppercase tiles; **off** → lowercase. Switching case only changes the grid, not stickers already on the board.
3. Tap a letter: skip recognition; create a sticker with that glyph, current default size/color/font (or last inspector values if we already have them).
4. **Placement (not jumbled):**
   - If `lastPlacedStickerId` is missing or that sticker was deleted: place at a stable start in the **visible viewport** (e.g. slightly left of center, board coords from Stage transform) so the first letter is on screen.
   - Else: place **to the right** of that sticker: `x = last.x + last.width + letterGap` (same named gap as lasso align), `y = last.y` (shared top, same as lasso).
   - Set `lastPlacedStickerId` to the new sticker. Multiple taps produce a left-to-right row with even spacing.
5. If the user **moves** the last placed sticker, the next tap still follows that sticker’s **current** position (anchor is the id, not a frozen point). Switching away from Add Sticker does not clear the anchor; the next grid tap continues the row unless the anchored sticker is gone.

**Sticker edit (Hand + one selection)**

- Size: S / M / L / XL chips (discrete, not free RGB or corner-drag resize in this plan).
- Color: swatches from `letterFills` only.
- Font: three styles — Lexend, Fredoka, Nunito.
