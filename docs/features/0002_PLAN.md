# 0002 — Tablet/Desktop Responsive Layout

## Context

HurufPad currently uses a salmon-colored header plus floating horizontal islands over the board. The first responsive-layout phase should make tablet and desktop feel closer to the supplied Excalidraw reference: a canvas-first workspace with compact top controls and a left-side property card.

User requirements, verbatim:

- "Right now this app doesn't looks good when opened in small phone."
- "I want to make the design responsive."
- "First phase, change the layout for tablet / desktop to looks like this excalidraw.com"
- "the inspector panel for changing colors etc is on the left in a portrait card style, instead of laid horizontally at the bottom"
- "Remove the salmon colored header, just put the \"HurufPad\" icon on the left, move the main toolbars to top middle, and the language selector on the right."
- "next phase we'll desgin for phone"

Phone-specific redesign is out of scope for this plan.

## Current Relevant Structure

### `src/App.tsx`

- `<header className="toolbar">` owns the salmon header, `HurufPad` brand, and language selector.
- `<main className="board-wrap">` owns `BoardCanvas` and all floating islands.
- `.tool-island` is already top-centered over the board and contains Hand, Pencil, Eraser, Lasso, Add Sticker, and Speak.
- `.brush-island` appears only while Pencil is selected and is currently a bottom horizontal island.
- `.inspector-island` appears only with one selected item in Hand and is currently a bottom horizontal island.
- `.letter-island` appears while Add Sticker is active and is a bottom keyboard-style grid.
- `.zoom-island` and `.action-island` are bottom-left and bottom-right.

### `src/index.css`

- `.app` is a vertical flex shell.
- `.toolbar` consumes `--toolbar-height`, uses `--toolbar` salmon background, and holds brand/language.
- `.board-wrap` fills the remaining height, not the full viewport.
- `.tool-island`, `.letter-island`, `.brush-island`, `.inspector-island`, `.zoom-island`, and `.action-island` are absolutely positioned over the board.
- `.brush-island` and `.inspector-island` share the same bottom horizontal layout rules.

### `docs/DESIGN.md`

- Still describes a slim header and bottom inspector/brush islands.
- Needs to describe the new tablet/desktop shell: brand left, tools top-middle, language right, property panel left.

## Layout Algorithm

### Top Overlay Controls

1. `main.board-wrap` becomes the full-viewport positioning root.
2. `BoardCanvas` receives the full `board-wrap` measured width and height.
3. Brand island is absolutely positioned at the top-left.
4. Tool island is absolutely positioned at the top center.
5. Language island is absolutely positioned at the top-right.
6. These controls use white/control-surface islands with subtle border and shadow, not the salmon toolbar background.

### Left Property Panel

1. Determine which property UI should be visible:
   - Pencil tool selected: show brush controls.
   - Hand tool with exactly one selected item: show selected-item inspector.
   - Otherwise: hide the left property panel.
2. Render the visible property UI in the same left-side portrait container.
3. For Pencil:
   - Color section updates `inkStyle.fill`.
   - Stroke section updates `inkStyle.brush`.
   - Weight section updates `inkStyle.weight`.
4. For selected letters:
   - Size section calls `chooseStyle('size', ...)`.
   - Color section calls `chooseStyle('fill', ...)`.
   - Font section calls `chooseStyle('fontFamily', ...)`.
5. For selected scribbles:
   - Color / Stroke / Weight sections call the existing scribble inspector handlers, preserving the current behavior where changes update both the selected scribble and the next scribble defaults.

### Collision Rules

1. Left property panel top offset is below the brand island.
2. Tool island stays centered and should not affect board measurement.
3. Language island stays right-aligned and should not affect board measurement.
4. Bottom Zoom, Make Sticker, and Add Sticker controls remain anchored to the board edges.

## Phases

### Phase 1 — App Shell Layout

Change `src/App.tsx` so brand, tools, and language all live as overlay islands inside `board-wrap`. Remove the salmon header from the rendered shell.

### Phase 2 — Left Property Panel

Move Pencil brush controls and selected-item inspector controls into the left portrait panel. Preserve all existing event handlers and board behavior.

### Phase 3 — Styling and Specs

Update `src/index.css`, `docs/DESIGN.md`, and `docs/features/0003_PLAN.md` to match the new tablet/desktop layout.
