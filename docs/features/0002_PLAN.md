# On-device scribble recognition (0002)

Replace the stub in [`src/board/recognize.ts`](../../src/board/recognize.ts) with a real on-device **A–Z / a–z** letter model. Ink never leaves the device. Pause, “transform now,” low-confidence picker, and sticker commit stay as built in 0001. **Do not edit** [`docs/features/0001_PLAN.md`](0001_PLAN.md).

## TensorFlow.js cost (why this runtime)

HurufPad targets phones, cheap Android tablets, Chromebooks. One letter is a **28×28** image and a **small CNN** (EMNIST-style), not a large vision model.

- **Download (once):** TF.js with **WASM** (CPU fallback) is typically on the order of **a few hundred KB to ~1–2 MB gzipped** for the library, plus a **small weight file** (often **~0.2–2 MB** for a letter CNN). After first load the **PWA caches both**, so later opens work offline.
- **RAM / CPU:** one inference is a few **milliseconds to tens of ms** on a cheap tablet CPU. No GPU required if WASM/CPU is the backend (WebGL is optional, not the minimum).
- **Minimum device:** current Chrome / Safari / Samsung Internet on a budget Android tablet or Chromebook is enough. Avoid a WebGL-only path so weak GPUs are not a hard requirement.
- **ONNX** can be a bit smaller in some setups; skip it this phase so we do not maintain two runtimes. Revisit only if the TF.js + WASM payload is too heavy in practice.

Ship a **converted pretrained EMNIST letters** model under `public/models/` (no Python training pipeline in this phase). Training/retrain can be a later doc, not this increment.

## Contract to keep

[`src/board/BoardCanvas.tsx`](../../src/board/BoardCanvas.tsx) `transformInk` calls `recognize(strokes)` and uses `RecognitionResult` (`glyph`, `confidence`, `alternatives`) plus `recognitionConfidenceThreshold`. The stub is **synchronous**; inference is **async**. Change only the adapter and the call site to `await` — picker/commit logic stays.

## Algorithms

**Rasterize**

1. Flatten pending strokes (board space).
2. Bounding box; pad to a square with margin so thin letters (I, l) still fill the frame.
3. Stroke width scaled so the bitmap looks like EMNIST ink (not hairline, not a blob).
4. Draw → resize 28×28 → normalize to the model’s input range.
5. Apply the **same** invert/rotate as training.

**Infer**

1. If the model is not loaded: await load (or treat as low confidence and open the picker — prefer await with a short timeout, then picker).
2. Run predict on-device only.
3. Softmax; `glyph` = top-1; `confidence` = top-1 probability; `alternatives` = short top-k glyphs (existing picker tiles).
4. Ambiguous pairs (c/C, o/O, etc.) naturally land in alternatives; do not silently commit a wrong case when confidence is below the existing threshold.

**PWA**

First visit downloads the model; service worker precaches `public/models/**`. No cloud OCR URL.
